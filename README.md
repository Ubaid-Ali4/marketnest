# MarketNest

MarketNest is a hyperlocal marketplace platform that helps people discover nearby shops and products quickly. It combines product discovery, location-based search, local business visibility, and role-based dashboards into one streamlined experience.

## About the platform

MarketNest is designed for modern neighborhood commerce. Customers can:

- search for products and stores near their current location
- browse by category and compare nearby options
- view shop details, product availability, and store information
- explore nearby businesses on a map-based experience
- contact stores directly for enquiries or stock checks

For shop owners, the platform supports:

- shop registration and listing setup
- product and inventory presentation
- dashboard tools to manage visibility and availability
- direct customer engagement through enquiry flows

For admins, the app includes a management view for reviewing merchants, storefronts, and marketplace activity.

## Key features

- Hyperlocal search with area radius filtering
- Product and shop discovery across multiple categories
- Nearby store exploration with map-style browsing
- Availability and verification badges
- Customer, shopkeeper, and admin dashboard views
- Search history and category-based navigation
- Responsive interface for desktop and mobile browsing

## Tech stack

- React + TypeScript
- Vite
- Tailwind CSS
- Leaflet for map-based shopping experience
- Lucide React icons

## Project structure

- `src/pages` — app screens and flows
- `src/components` — reusable UI components
- `src/context` — app state and shared data
- `src/data` — mock marketplace and category data
- `src/utils` — support utilities

## Run locally

### Prerequisites

- Node.js 18+

### Installation

```bash
npm install
```

### Start development server

```bash
npm run dev
```

Then open the local Vite URL shown in the terminal, usually:

```text
http://localhost:3000
```

## Why it matters

MarketNest brings local shopping online in a simple, fast, and trust-driven way. It makes it easier for customers to find the right products close to home while helping local businesses become more discoverable and more visible in their communities.
